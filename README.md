# Folha PIX — instaladores

Aplicativo de **pagamento de salários via PIX** (API Multipag do Sicredi).
Este repositório serve só para **download dos instaladores**.

> Não sabe qual é o seu Mac? Menu  › **Sobre Este Mac**: se aparecer “Chip Apple M…”, use
> *Mac com chip Apple*; se aparecer “Processador Intel…”, use *Mac Intel*.

## Instalação

**Windows**
1. Abra o arquivo `Folha-PIX-Windows.exe`.
2. Se aparecer “O Windows protegeu o computador”, clique em **Mais informações › Executar assim mesmo**.
3. Siga o instalador. O atalho **Folha PIX** é criado na área de trabalho.

**Mac**
1. Abra o arquivo `.dmg` e arraste o **Folha PIX** para a pasta **Aplicativos**.
2. Na primeira vez, clique com o **botão direito** no app › **Abrir** › **Abrir**.
   No macOS 15 ou mais novo: tente abrir uma vez, depois vá em
   **Ajustes do Sistema › Privacidade e Segurança** e clique em **Abrir Mesmo Assim**.

Os avisos aparecem porque o aplicativo ainda não tem assinatura digital de desenvolvedor.

## Primeiro acesso

Ao abrir, crie o usuário administrador. Use **✨ Sugerir senha forte** e
**imprima ou salve a folha de recuperação** — não existe recuperação de senha.
